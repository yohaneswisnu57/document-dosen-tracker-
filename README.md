# Document Tracker Boilerplate

A React + Vite starter for a document tracking dashboard.

## Included

- Dashboard shell with sidebar, overview cards, status board, activity feed, and document table
- Reusable React components under `src/components`
- Sample dataset in `src/data/sampleData.js`
- Centralized styling in `src/styles`

## Start

1. Install dependencies with `npm install`
2. Run the app with `npm run dev`
3. Build for production with `npm run build`

## Suggested next steps

- Add routing for dashboard, document detail, and reports pages
- Replace sample data with API calls or local persistence
- Add search, filters, pagination, and upload workflows
- Introduce state management when the app grows beyond local component state
